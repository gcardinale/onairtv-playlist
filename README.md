# onairtv-playlist

Lista personale di canali in chiaro italiani in formato M3U, usata da [OnAirTV](https://github.com/gcardinale/AmazonFireM3u).

## File

- `lista.m3u` — playlist M3U con canali FTA italiani (Rai, Mediaset, La7, ecc.) + EPG XMLTV references

## URL di download

```
https://raw.githubusercontent.com/<user>/onairtv-playlist/main/lista.m3u
```

Da incollare nel wizard di OnAirTV (campo "URL playlist M3U") oppure nel form "Aggiungi playlist".

## Aggiornamenti

Quando una URL stream cambia o un canale non si vede più, modifica direttamente questo file e fai push. Il prossimo refresh dell'app riscaricherà la versione aggiornata.

## Note

I link puntano ai CDN ufficiali Rai (mediapolis.rai.it), Mediaset (msf.cdn.mediaset.net), Sky (TV8/akamaized.net), La7, ecc. Nessuno stream è ricodificato o ridistribuito da server terzi. La lista è una raccolta di riferimenti pubblicamente documentati.
